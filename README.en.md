# Alamofire Test

A trial screen with Alamofire linked in.

## What it does

The screen shows a globe and the text `Request.request`. The code declares a request to `https://swapi.dev/api/films/`. The screen does not start that request.

## Stack

SwiftUI, Alamofire, CocoaPods.

## Run

```bash
git clone https://github.com/dpogonia/AlamofireTest-OTUS.git
cd AlamofireTest-OTUS
pod install
open AlamofireTest.xcworkspace
```

Run the **AlamofireTest** scheme on an iPhone simulator.
