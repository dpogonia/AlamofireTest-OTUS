# Alamofire Test

Пробный экран с подключенным Alamofire.

## Что умеет приложение

На экране глобус и текст `Request.request`. В коде объявлен запрос к `https://swapi.dev/api/films/`. С экрана этот запрос не запускается.

## Стек

SwiftUI, Alamofire, CocoaPods.

## Запуск

```bash
git clone https://github.com/dpogonia/AlamofireTest.git
cd AlamofireTest
pod install
open AlamofireTest.xcworkspace
```

Запустите схему **AlamofireTest** на симуляторе iPhone.
